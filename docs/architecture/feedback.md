# Events

| Event | Sound volume | Haptic |
| --- | --- | --- |
| `tap` | 0.5 | selection |
| `op` | 0.5 | selection |
| `undo` | 0.5 | selection |
| `combine` | 0.7 | light impact |
| `error` | 0.7 | error notification |
| `win` | 0.9 | success notification |

# Behavior

* Sounds respect the silent switch (`playsInSilentMode: false`) and mix with the player's music (`interruptionMode: 'mixWithOthers'`).
* Players are created lazily on first use and rewound before each play, so rapid taps restart the sound.
* Haptics are skipped on web.
* Settings are toggled in **Settings → Feedback** and stored under `numberwright.feedback.v1`. See [Persistence](/architecture/persistence.md).

The `expo-audio` config plugin is set to foreground playback only, with no microphone permission and no background audio. See [App config](/build/app-config.md).

# Sound files

The WAVs in `assets/sounds/` are generated by `scripts/make-sounds.py`. Edit the script and re-run it rather than editing the files. See [Generated assets](/build/generated-assets.md).
