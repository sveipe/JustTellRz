# Overview

Players combine number tiles with + − × ÷ to hit a target. There are three practice levels and a daily puzzle that is the same for everyone. The app is free and shows occasional interstitial ads (see [AdMob integration](/ads/admob-integration.md)).

Publisher: JustTell. App ID on both platforms: `co.justtell.numberwright`.

# Stack

| Part | Choice |
| --- | --- |
| Framework | Expo SDK 58, React Native 0.88, React 19.3, TypeScript (strict) |
| Native projects | Generated by `expo prebuild` (Continuous Native Generation); `android/` and `ios/` are gitignored |
| Storage | `@react-native-async-storage/async-storage`, on device only |
| Sound and haptics | `expo-audio`, `expo-haptics` |
| Icons | `@expo/vector-icons` (Ionicons) |
| Ads | `react-native-google-mobile-ads` (AdMob + Google UMP consent) |
| Builds | Local Gradle builds on Windows, or EAS Build |
